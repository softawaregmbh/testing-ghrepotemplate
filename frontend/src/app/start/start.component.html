Start

General Rules

  • Follow Angular's Styleguide
  • Keep it simple
  • Use Kendo components whenever possible
  • Use Tailwind for layouting

Included Libraries

  • Kendo UI : Component Lib (e.g. grid, popups, inputs, ...)
  • Tailwind : Styling for custom components & Layouting
  • Fontawesome : Icons like
  • ngx-translate : Translation Lib
  • luxon : DateTime

Folder Structure

  • All logically related/connected features of the app should be grouped into subfolders (e.g. admin features can be grouped in an 'admin' folder)
  • All components should be loaded lazily by default if possible.
  • Lazy loading is handled by 'app.routes.ts'.

Components

Components should be standalone by default.
This template distinguishes between the following types of components
  • Routed components
    Components that have an active routing configuration in a routing-module (a route to that component exists).
    Routed components are not shared in any way by default.
  • Unrouted components
    Components that have no routing configuration (no route to that component exists).
    Unrouted components can be either located inside a parent-component folder or shared within the containing module.

Shared things (services, dtos, models, ...)

The '/shared' folder holds assets like services or models that are used by multiple sub-modules.
